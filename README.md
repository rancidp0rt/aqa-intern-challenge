Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Что исправлено
--------------

- WRAPPER: класса `sc-dino-typography-h` на странице больше нет, виджет не находился
- кнопка "Написать нам": `[class^=btn]` находит несколько элементов (лайк/дизлайк статьи и т.д.), поменял на `data-test`
- `getPopularArticles()`: `all()` не ждет пока загрузится список, добавил ожидание
- заголовок проверялся через `textContent()` сразу после клика, там еще был старый текст. Сделал через `toHaveText`
- куки-попап появляется не сразу, иногда тест падал на его закрытии. Закрываю через `addLocatorHandler`
- `goto` жду до `domcontentloaded`, на `load` страница иногда грузилась дольше 30 сек

Добавил тест на закрытие виджета.

Иногда виджет на странице не появляется совсем (в консоли ошибка CORS на help.uchi.ru/widget), тогда тесты падают на открытии виджета. Если перезапустить, проходят.
